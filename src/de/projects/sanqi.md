# Sanqi![](/assets/sanqi/app-icon.svg)

![Sanqi, das Brettspiel, bei dem die Figuren zusammenarbeiten müssen](/assets/sanqi/de/feature-graphic.png)

Die Rust-Engine stellt die Regeln sowohl für das Kommandozeilenspiel als auch für den mit Flutter entwickelten Mobilprototyp bereit. Beide Seiten können von einem Menschen oder vom Computer gespielt werden. So lässt sich zu zweit spielen oder allein üben.

Der Mobilprototyp bietet Beispielzüge, eine Vorschau auf unterstützende Spielfiguren und eine Rückgängig-Funktion. Partien lassen sich als Zugtext speichern und wiederherstellen. Das Repository enthält die Spielregeln in mehreren Sprachen, darunter Deutsch und Englisch.

Wir arbeiten daran, Sanqi zuerst für Android zu veröffentlichen. Eine Version für das iPhone soll später folgen.
