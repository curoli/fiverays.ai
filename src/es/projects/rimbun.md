# Rimbun![](/assets/projects/rimbun.svg)

Rimbun permite abrir un documento completo y comparar el texto principal de cada sección con las alternativas publicadas. Quien escribe puede editar el borrador de una sección y publicarlo como otra versión.

Queremos que muchas personas puedan redactar y revisar documentos en conjunto.

El prototipo usa Vue para leer, comparar y editar, y un servidor Rust para cuentas y documentos. El repositorio explica cómo ejecutarlo localmente con PostgreSQL.

[Código fuente en GitHub](https://github.com/curoli/rimbun)
