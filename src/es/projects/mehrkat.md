# Mehrkat

Busca una empresa o símbolo bursátil y elige una cotización. Los filtros de bolsa, país y sector acotan la selección. Mehrkat genera un informe con citas para consultar las fuentes.

Intenta obtener el texto de los artículos y, si no puede, utiliza resultados de búsqueda citados. El repositorio explica cómo usarlo en local con tu clave de la API de OpenAI.
