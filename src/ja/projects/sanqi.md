# Sanqi![](/assets/sanqi/app-icon.svg)

![三棋、駒同士の連携が必要なボードゲーム](/assets/sanqi/ja/feature-graphic.png)

Rust エンジンはコマンドライン版と Flutter のモバイル試作版にルールを提供します。どちらの側も人間かコンピューターが担当でき、二人での対戦や一人での練習が可能です。

モバイル版では手の例や援護する駒を確認でき、手を取り消せます。対局は手順テキストとして保存・復元できます。リポジトリには複数言語のルールがあります。

現在 Android 版 Sanqi の公開を準備しています。その後に iPhone 版を公開する予定です。
