# Five Rays AI

**私たちは開発者向けツール、ゲーム、実験的なアプリケーションを作っています。**

## [プロジェクト](projects/)

主なプロジェクトをご紹介します。

まずは、このサイトに使っている Markdown サイトジェネレーター [Ryllis](projects/ryllis.html) をご覧ください。ボードゲーム [Sanqi](projects/sanqi.html) でコンピューターと対戦したり、[Rimbun](projects/rimbun.html) で草稿を比較したり、ブラウザーゲーム [Spreat](projects/spreat.html) で連鎖反応を起こしたりできます。

[Mehrkat](projects/mehrkat.html) は株式ニュースを出典付きでまとめます。[Slofox](projects/slofox.html) では、仮想スタジオで二人のアニメーション司会者が会話します。[TrayStack](projects/traystack.html) は契約書の該当箇所の検索と確認を支援します。
