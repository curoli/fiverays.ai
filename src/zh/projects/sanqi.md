# Sanqi![](/assets/sanqi/app-icon.svg)

![三棋，一款需要棋子协作的棋盘游戏](/assets/sanqi/zh/feature-graphic.png)

Rust 引擎为命令行版和 Flutter 移动原型提供规则。双方均可由真人或电脑操控，既能双人对弈，也能独自练习。

移动原型提供走法示例、支援棋子预览和悔棋功能，可将对局保存为走法文本并恢复。代码库提供多语言规则。

我们正在准备发布 Android 版 Sanqi，之后计划推出 iPhone 版。
