# Five Rays AI

**We’re a software factory building developer tools, games, and experimental applications.**

## [Projects](projects/)

Start with [Ryllis](projects/ryllis.html), the Markdown site builder behind this website. You can play the board game [Sanqi](projects/sanqi.html) against the computer, compare alternative drafts in [Rimbun](projects/rimbun.html), or trigger chain reactions in the browser game [Spreat](projects/spreat.html).

[Mehrkat](projects/mehrkat.html) puts together stock-news briefings with sources. [Slofox](projects/slofox.html) stages conversations in a virtual studio with two animated hosts, and [TrayStack](projects/traystack.html) helps you find and review passages in contracts.
