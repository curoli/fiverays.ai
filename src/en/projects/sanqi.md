# Sanqi

The Rust engine supplies the rules for both the command-line game and the Flutter mobile prototype. Either side can be played by a person or the computer, so you can play with someone else or practice on your own.

The mobile prototype offers example moves, previews of supporting pieces, and an undo action. It can save and restore games as move text. The repository includes the rules in several languages, including English and German.

We’re working on publishing Sanqi for Android first, with an iPhone release planned for later.
