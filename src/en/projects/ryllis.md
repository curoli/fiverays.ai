# Ryllis

Write each language in its own directory and give translated pages the same relative path. Ryllis turns those pages into HTML, with links that let readers switch languages while staying on the corresponding page.

MiniJinja can build lists from the site's page index. On this site, for example, the news archive sorts articles by their dated file paths. Ryllis also has a local preview and a check command for broken internal Markdown links and missing translations.
