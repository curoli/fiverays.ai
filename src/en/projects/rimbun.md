# Rimbun

Rimbun makes alternative wording visible in the reading experience. A reader can open a full document and then compare the main version of a section with its published alternatives. Writers can edit a section draft and publish it as another version.

Our goal is for many contributors to draft and revise documents together.

The prototype includes a Vue interface for reading, comparing, and editing, plus a Rust backend for accounts and document storage. The repository documents how to run the prototype locally with PostgreSQL.
