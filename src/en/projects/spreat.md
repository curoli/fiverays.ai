# Spreat

On each turn, a player adds an atom to an empty hexagon or one they already control. When a hexagon holds as many atoms as it has neighbors, it bursts and sends an atom to each neighbor. Those atoms can take over neighboring cells and trigger further bursts.

The goal is to take over the other players' atoms. You can open the static game in a browser, and the repository explains the rules and how to run it locally.
