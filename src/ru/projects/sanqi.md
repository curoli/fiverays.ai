# Sanqi

Движок на Rust реализует правила игры для командной строки и мобильного прототипа на Flutter. За любую сторону может играть человек или компьютер.

В прототипе есть примеры ходов, просмотр поддерживающих фигур и отмена хода. Партии сохраняются и восстанавливаются в виде текста ходов. Правила на нескольких языках находятся в репозитории.

Мы готовим выпуск Sanqi для Android. Версию для iPhone планируем выпустить позже.
