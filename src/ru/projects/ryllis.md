# Ryllis![](/assets/projects/ryllis.png)

Храните каждый язык в отдельной папке с одинаковыми относительными путями для переводов. Ryllis создаёт HTML и позволяет переключаться между версиями текущей страницы.

MiniJinja строит списки из индекса страниц. Здесь архив новостей сортируется по датам в путях файлов. Ryllis также поддерживает локальный предпросмотр и проверяет внутренние ссылки и наличие переводов.
