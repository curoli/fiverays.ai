# Rimbun![](/assets/projects/rimbun.svg)

В Rimbun можно открыть документ и сравнить основной текст раздела с опубликованными вариантами. Авторы могут отредактировать черновик раздела и опубликовать его как новую версию.

Цель проекта — дать многим участникам возможность вместе составлять и редактировать документы.

Прототип использует Vue для чтения, сравнения и правок, а Rust — для учётных записей и хранения документов. В репозитории описан локальный запуск с PostgreSQL.
