# Mehrkat![](/assets/projects/mehrkat.svg)

Найдите компанию или тикер и выберите биржевую котировку. Фильтры по бирже, стране и отрасли сужают выбор. Mehrkat готовит обзор со ссылками на источники.

Приложение пытается получить текст статей и при неудаче может опираться на результаты поиска со ссылками. Инструкции по запуску со своим ключом API OpenAI есть в репозитории.
