# Mehrkat![](/assets/projects/mehrkat.svg)

কোম্পানি বা শেয়ারের প্রতীক খুঁজে একটি তালিকাভুক্ত শেয়ার বেছে নিন। এক্সচেঞ্জ, দেশ বা খাত দিয়ে ছাঁকতে পারেন। Mehrkat যাচাইযোগ্য সূত্রসহ সারাংশ তৈরি করে।

অ্যাপটি নিবন্ধের লেখা আনার চেষ্টা করে। তা না পারলে উৎসসহ অনুসন্ধানের ফল ব্যবহার করতে পারে। নিজের OpenAI API কী দিয়ে স্থানীয়ভাবে চালানোর নির্দেশ রিপোজিটরিতে আছে।
