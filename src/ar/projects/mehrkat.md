# Mehrkat![](/assets/projects/mehrkat.svg)

ابحث عن شركة أو رمز سهم واختر إدراجًا. يمكنك التصفية حسب البورصة أو البلد أو القطاع. يُنشئ Mehrkat موجزًا بإحالات تتيح مراجعة المصادر.

يحاول التطبيق جلب نص المقالات، ويمكنه استخدام نتائج بحث موثقة إن تعذّر ذلك. يشرح المستودع التشغيل محليًا باستخدام مفتاح OpenAI API الخاص بك.
