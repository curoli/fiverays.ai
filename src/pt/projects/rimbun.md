# Rimbun

O Rimbun permite ler um documento completo e comparar a versão principal de cada secção com alternativas publicadas. Os autores podem editar o rascunho de uma secção e publicá-lo como outra versão.

Queremos que muitos colaboradores possam redigir e rever documentos em conjunto.

O protótipo combina uma interface em Vue para leitura, comparação e edição com um servidor em Rust para contas e armazenamento. O repositório descreve como o executar localmente com PostgreSQL.
