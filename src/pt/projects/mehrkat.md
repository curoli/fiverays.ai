# Mehrkat

Pesquise uma empresa ou um símbolo e escolha uma cotação. Pode filtrar por bolsa, país ou setor. O Mehrkat prepara um resumo com citações para consultar as fontes.

A aplicação tenta obter o texto dos artigos. Se não conseguir, pode recorrer a resultados de pesquisa citados. O repositório explica como a executar com a sua chave da API da OpenAI.
