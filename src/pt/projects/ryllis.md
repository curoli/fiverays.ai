# Ryllis

Guarde cada idioma numa pasta própria, mantendo o mesmo caminho relativo para as traduções. O Ryllis gera as páginas HTML e permite mudar de idioma na página correspondente.

O MiniJinja permite criar listas a partir do índice de páginas. Aqui, as notícias são ordenadas pela data no caminho. O Ryllis também oferece pré-visualização local e um comando que verifica ligações internas e traduções em falta.
