# Aviso de privacidade para aplicações offline

Este aviso abrange a utilização, no seu dispositivo, das aplicações offline da Five Rays AI que incluem uma ligação para este aviso.

## Dados no seu dispositivo

A aplicação funciona offline e não envia dados à Five Rays AI. Não recebemos estatísticas de utilização nem relatórios de falhas e não temos acesso aos dados locais.

Se a aplicação guardar definições ou conteúdos, estes ficam no dispositivo. Pode apagar os dados locais pela aplicação ou pelas definições do dispositivo, quando essa opção existe. Os ficheiros exportados e as cópias de segurança são geridos separadamente.

## Serviços externos

Se recorrer a uma loja de aplicações ou a um serviço de cópias de segurança, o fornecedor trata os dados de acordo com o seu próprio aviso. O mesmo se aplica a sítios externos como o GitHub.
