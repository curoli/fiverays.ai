# Rimbun![](/assets/projects/rimbun.svg)

Dans Rimbun, les lecteurs peuvent ouvrir un document complet et comparer le texte principal de chaque section à ses variantes publiées. Les auteurs peuvent modifier un brouillon de section et le publier comme nouvelle version.

Notre objectif est de permettre à de nombreux contributeurs de rédiger et de réviser des documents ensemble.

Le prototype combine une interface Vue de lecture, de comparaison et d’édition et un service Rust pour les comptes et les documents. Le dépôt indique comment le lancer localement avec PostgreSQL.
