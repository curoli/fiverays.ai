# Mehrkat

کمپنی یا حصص کا نشان تلاش کرکے فہرست شدہ سکیورٹی منتخب کریں۔ ایکسچینج، ملک اور شعبے کے فلٹر انتخاب کو محدود کرتے ہیں۔ Mehrkat حوالوں کے ساتھ خلاصہ بناتا ہے۔

ایپ مضمون کا متن حاصل کرنے کی کوشش کرتی ہے۔ ناکامی پر حوالہ شدہ تلاش کے نتائج استعمال کر سکتی ہے۔ اپنی OpenAI API کلید کے ساتھ مقامی اجرا کی ہدایات ریپوزٹری میں ہیں۔
