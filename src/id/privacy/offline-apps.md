# Pemberitahuan privasi untuk aplikasi luring

Pemberitahuan ini mencakup penggunaan aplikasi luring Five Rays AI yang menautkannya di perangkat Anda.

## Data di perangkat Anda

Aplikasi bekerja secara luring tanpa mengirim data kepada kami. Kami tidak menerima statistik penggunaan atau laporan kerusakan dan tidak dapat mengakses data setempat.

Setelan dan konten disimpan di perangkat Anda. Hapus melalui aplikasi atau pengaturan perangkat jika tersedia. Kelola berkas ekspor dan cadangan secara terpisah.

## Layanan eksternal

Penyedia toko aplikasi atau layanan pencadangan mengelola data menurut pemberitahuan mereka sendiri. Hal yang sama berlaku untuk situs luar seperti GitHub.
