# Mehrkat![](/assets/projects/mehrkat.svg)

Cari perusahaan atau kode saham lalu pilih pencatatan. Saring menurut bursa, negara, atau sektor. Mehrkat membuat ringkasan dengan rujukan yang dapat diperiksa.

Aplikasi mencoba mengambil isi artikel. Jika gagal, aplikasi dapat memakai hasil pencarian yang disertai rujukan. Repositori menjelaskan cara menjalankannya dengan kunci API OpenAI Anda.

[Kode sumber di GitHub](https://github.com/curoli/mehrkat)
