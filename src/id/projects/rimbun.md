# Rimbun![](/assets/projects/rimbun.svg)

Pembaca dapat membuka dokumen utuh dan membandingkan versi utama setiap bagian dengan alternatif yang telah terbit. Penulis dapat menyunting draf bagian dan menerbitkannya sebagai versi lain.

Tujuannya agar banyak kontributor dapat menyusun dan merevisi dokumen bersama.

Prototipe memakai Vue untuk membaca, membandingkan, dan menyunting, serta Rust untuk akun dan penyimpanan. Repositori menjelaskan cara menjalankannya dengan PostgreSQL.
