# Mehrkat

Şirket veya hisse kodu arayıp bir kotasyon seçin. Borsa, ülke veya sektör filtreleri seçimi daraltır. Mehrkat kaynakları gösteren bir özet hazırlar.

Makale metinlerine erişemezse kaynak gösterilen arama sonuçlarını kullanabilir. Depoda kendi OpenAI API anahtarınızla çalıştırma adımları bulunur.
